Acerca de PowerFit

Un sistema de gestión integral para gimnasios, desarrollado en Django.

Sobre el proyecto

PowerFit es una aplicación web full-stack pensada para administrar las operaciones diarias de un gimnasio. Permite gestionar socios, entrenadores, rutinas de entrenamiento y registrar asistencias de manera simple y visual.

El sistema fue desarrollado como proyecto final del curso de Python/Django, aplicando los conceptos aprendidos a lo largo de la cursada: modelos, formularios, migraciones, vistas basadas en funciones y clases, autenticación, mensajería y despliegue.

Funcionalidades principales
  • ABM completo de socios, entrenadores y rutinas
  • Registro y control de asistencias
  • Gestión de imágenes (avatares y fotos)
  • Búsqueda de rutinas con Q objects
  • Sistema de autenticación y perfiles
  • Mensajería privada entre usuarios
Tecnologías utilizadas
  • Backend: Python 3.12 + Django 6.0
  • Base de datos: SQLite
  • Frontend: Bootstrap 5 + Bootstrap Icons
  • Imágenes: Pillow
  • Patrón: MVT (Model - View - Template)
  • Despliegue: PythonAnywhere

Sobre el autor

Este proyecto fue desarrollado por un estudiante de Python/Django como entrega final del curso, con el objetivo de poner en práctica los conocimientos adquiridos: modelado de datos, herencia de templates, CBV, mixins, decoradores, autenticación, mensajería y despliegue en la nube.
